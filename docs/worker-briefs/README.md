# Worker Brief Templates

Reusable prompt templates for AEON Watch supervised Copilot CLI tasks.

Each brief should make model, effort, context, permissions, acceptance criteria, and output format explicit. Watch should fill these in before launching a worker.

Initial templates to create:

- `implementation.md`
- `architecture-review.md`
- `research.md`
- `readme-polish.md`
- `code-review.md`
